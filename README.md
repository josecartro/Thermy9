# Thermy9

A small Windows app for printing machine labels, cable flags and images on the
PAPERANG P2S.

- Live preview, adjustable text, borders and icons.
- Cable flags with 2 or 4 columns and copies per row.
- Save your own presets.

## Get started

Windows 10/11 (64-bit) and Bluetooth required. **The installer is not published
yet**; a test on another PC is pending. For now, [build from source](docs/installing.md#build-from-source).

Once installed:

1. Open **Thermy9** and find your printer in **Printer settings**.
2. Choose **Machine label**, **Cable flags** or **Image print**.
3. Edit, check the preview and print.
